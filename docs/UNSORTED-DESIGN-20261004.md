# Unsorted design exploration — October 4, 2026

Nate rejected the first sorting UI as cluttered, wordy and stressful. The revised
brief: opening Unsorted starts immediately with the first sticky. OSAT should
surface a related node or branch, propose a new node where appropriate, or let
it remain freely on Sky. Users should not search every topic to find a home.
Keep batches small and attention on one thought at a time.

Three independent mockups were generated with the built-in image tool, using a
live capture of the existing OSAT Sky as the style and shell reference. These are
proposed UI concepts; no redesigned sorting behavior is implemented yet.

Display order in the chat (the selection mapping):

1. `outputs/unsorted-concepts-20261004/01-match-on-map.png`: one sticky alongside
   the recommended existing branch and its nearby notes on the canvas.
2. `outputs/unsorted-concepts-20261004/02-one-thought-one-home.png`: a minimal
   single-sticky rail and a preview of a recommended new node on Sky.
3. `outputs/unsorted-concepts-20261004/03-five-on-sky.png`: a five-sticky visual
   tray, with one active sticky previewed freely on Sky.

The images and reference remain local and are ignored by Git. Each uses the
same charcoal/system-type visual language and a restrained cobalt primary action.
No scrolling filing form or topic dropdown is part of the new concept direction.
The displayed example recommendations are design data, not live local-AI results.
Wait for Nate's visual selection or refinement before changing the sorting UI.
Preserve canonical records, installed apps and the native-testing pause.
