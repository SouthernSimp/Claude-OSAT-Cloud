## Behavior

Open a current note and choose **Note AI**. Summarize, Untangle and Next steps
explicitly share the current note's snapshot. Other notes are unshared until
selected; their names are visible before the request and on the response.
No implicit workspace map, Calendar, About Me, file or cloud context is sent.
Current-note content is limited to 8,000 characters. Selected context shares up
to 4,000 characters total, at most 1,600 per extra note, spread across at most
seven selected notes. The panel discloses truncation.

Responses use the existing local streaming runtime and Markdown renderer. Stop,
close, note changes and unmount cancel work; stale deltas/completions are ignored.
Unavailable/error states keep the original note editable. Partial stopped/error
responses cannot be saved. Nothing applies model-generated action blocks.

Review or edit the answer, then choose **Save as linked note**. This creates one
new canonical note in the source's current folder, linked through the existing
wikilink format. The source record is never written, including concurrent edits.
Repeated save clicks reuse the proposal ID. Missing, archived or trashed sources
prevent saving. Existing save status/recovery reports durability. Responses not
explicitly saved are transient and disappear when the panel closes.

The preview also exposed an existing window-size blocker: open pop-outs remained
off-screen after the viewport shrank. Their shared placement code now keeps rooms
within the available viewport, leaving the dock clear and preserving room content.
This changes temporary window bounds, not note/Sky geometry or storage keys.
