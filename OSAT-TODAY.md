# OSAT V2

September 16: source and installed Mac app include recovery/restore safeguards and immediate board-scope updates. See [current work](/Users/nate/Desktop/Projects/NateOS/CURRENT-WORK.md).

Use `/Applications/OSAT V2.app` for the redesigned Notes and Mindmap. It keeps its own data; the everyday `/Applications/OSAT.app` still opens your original workspace.

- Notes: folders (nested), pins, archive, trash, `#tags`, `[[links]]` with backlinks, Write / Split / Read modes.
- Mindmap: every note is a sticky card. Boards can show every note, one folder, or only what you add. Sort by tag makes frames; frames move their cards.
- Removing a card from a board never deletes the note. Trash lives in Notes and can be emptied there.
- Settings → Download JSON backup saves the whole workspace including boards; Restore accepts V1 backups.
